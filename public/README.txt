Static assets for Hi-Tech Glass Films.

gallery/media/   Real project photos and video. Generated by
                 scripts/import-project-media.sh from the project-media/ drop
                 and described in src/lib/projectMedia.ts.
gallery/*/       Licensed stock photography (Pexels) used for the hero and
                 supporting imagery.
favicon.ico      Fallback icon. The primary icon and the 1200x630 share card
                 are generated at build time by src/app/icon.tsx and
                 src/app/opengraph-image.tsx — no og.png file is needed.
